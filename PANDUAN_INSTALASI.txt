======================================================================
     PANDUAN LENGKAP INSTALASI & PENGGUNAAN BREMSPACE ERP & POS
======================================================================
Terima kasih telah memilih Bremspace ERP & POS System!
Aplikasi ini dirancang untuk bekerja secara mandiri (Localhost & Wi-Fi),
cepat, aman, dan dapat diakses dari komputer kasir, laptop, tablet,
hingga smartphone (Android & iPhone/iPad).

Ikuti langkah mudah di bawah ini untuk memulai:

----------------------------------------------------------------------
1. LANGKAH INSTALASI DI KOMPUTER WINDOWS (PC / LAPTOP KASIR)
----------------------------------------------------------------------
Prasyarat: Komputer Windows 10 atau Windows 11 (64-bit).
(Sistem installer akan otomatis mengaktifkan WSL2/Docker tanpa biaya lisensi).

Cara Menjalankan:
1. Ekstrak seluruh isi file ZIP ini ke folder komputer Anda (misal di C:\Bremspace).
2. Klik ganda file: "start-install.bat".
3. Jendela instalasi akan terbuka dan memeriksa kondisi sistem Anda secara otomatis.
4. Anda akan melihat "Kode Mesin (Challenge Code)", contoh: BREM-XXXX-YYYY-ZZZZ.
5. Klik tautan WhatsApp yang muncul di layar untuk mengirim kode tersebut ke 
   Developer Bremspace resmi guna mendapatkan "Kode Aktivasi".
6. Tempelkan (paste) Kode Aktivasi yang Anda terima, lalu tekan Enter.
7. Aplikasi dan database lokal akan menyala otomatis di latar belakang!
8. Browser Anda akan terbuka otomatis ke alamat:
   http://localhost:1741

----------------------------------------------------------------------
2. LANGKAH INSTALASI DI LINUX / VPS CLOUD SERVER
----------------------------------------------------------------------
1. Ekstrak file dan buka terminal di folder aplikasi.
2. Jalankan perintah:
   chmod +x start-install.sh && ./start-install.sh
3. Masukkan Kode Aktivasi yang diberikan oleh Developer Bremspace.

----------------------------------------------------------------------
3. LANGKAH INSTALASI DI SMARTPHONE ANDROID (VIA TERMUX - TANPA ROOT)
----------------------------------------------------------------------
Khusus untuk Anda yang ingin menjadikan HP Android sebagai server kasir mandiri:
1. Pasang aplikasi "Termux" dari F-Droid (bukan Play Store lama).
2. Buka aplikasi Termux, lalu salin folder aplikasi ini ke penyimpanan Termux.
3. Jalankan perintah:
   bash start-termux.sh
4. Masukkan Kode Aktivasi saat diminta.
5. Browser Google Chrome di HP Anda akan langsung membuka aplikasi di port 1741.

----------------------------------------------------------------------
4. CARA MENGAKSES DARI BANYAK PERANGKAT (KASIR, HP, IPHONE, IPAD)
----------------------------------------------------------------------
Aplikasi ini sudah mendukung Multi-Device di jaringan Wi-Fi toko yang sama:
1. Pastikan komputer server dan HP/iPad kasir terhubung ke Wi-Fi yang sama.
2. Saat instalasi selesai, terminal akan menampilkan alamat IP jaringan Anda, contoh:
   http://192.168.1.15:1741
3. Buka browser Safari (iPhone/iPad) atau Chrome (Android), lalu ketik alamat IP tersebut.
4. Tips Tambahan: Klik "Add to Home Screen" (Tambahkan ke Layar Utama) di browser HP 
   agar aplikasi tampil layar penuh layaknya aplikasi native tanpa bar browser!

----------------------------------------------------------------------
5. PENGATURAN AWAL SISTEM (SETUP WIZARD)
----------------------------------------------------------------------
Saat pertama kali membuka aplikasi:
1. Anda akan diarahkan ke halaman Setup Wizard (install.php).
2. Pilih database: 
   - Pilih "SQLite" untuk setup instan tanpa repot (Sangat Direkomendasikan).
   - Atau pilih "MySQL" untuk kapasitas transaksi data enterprise skala besar.
3. Masukkan nama toko Anda dan buat password akun Administrator.
4. Klik "Selesai & Jalankan Sistem". Aplikasi siap digunakan untuk transaksi kasir!

----------------------------------------------------------------------
6. CARA MENGHENTIKAN ATAU MEMULAI ULANG APLIKASI
----------------------------------------------------------------------
- Untuk Mematikan Server : Klik ganda file "stop-server.bat"
- Untuk Menyalakan Kembali: Klik ganda file "start-install.bat" (server langsung aktif tanpa perlu aktivasi ulang).

----------------------------------------------------------------------
BUTUH BANTUAN TEKNIS?
----------------------------------------------------------------------
Hubungi tim dukungan resmi Bremspace melalui kontak WhatsApp yang tertera saat instalasi.
Selamat berbisnis dengan Bremspace ERP & POS!
