# T-29 — Sidebar Ganti Cabang Fix (COMPLETED)

## Summary
Fixed sidebar cabang switching to call API AUTH-02 (`POST /api/select-branch`) instead of web route, with full page reload to refresh all cabang-dependent modules.

## Changes Made

### `resources/views/layouts/backoffice.blade.php`
1. **Removed old form-based approach**: Replaced traditional `<form method="POST" action="{{ route('pilih-cabang') }}">` with Alpine.js component that calls API endpoint
2. **Created `branchSwitcher` Alpine component**:
   - `switchBranch(cabangId)` method calls `POST /api/select-branch` with CSRF token
   - Uses `fetch` with `credentials: 'same-origin'` for session cookie
   - On success: `window.location.reload()` to re-query all modules (Dashboard, POS, WMS)
   - Loading state: `switchingBranch` shows "⟳ Beralih..." during transition
   - Error handling with alert
3. **Global event listener**: `open-branch-modal` event opens modal via `branchSwitcher.branchModal = true`
4. **Removed legacy `x-data` from body tag**: Cleaned up conflicting Alpine state

### API Endpoint (Already Existed - `AuthController@selectBranch`)
- Validates `cabang_id` exists and user has access
- Updates session: `cabang_id`, `cabang_nama`
- Returns JSON response
