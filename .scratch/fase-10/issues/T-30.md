# T-30 — Responsive UI Optimization (COMPLETED)

## Summary
Optimized UI for mobile devices (320px-375px) with custom Tailwind breakpoints, touch-friendly targets, off-canvas sidebar, and POS cart bottom sheet.

## Changes Made

### 1. Tailwind 4 Custom Breakpoints (`resources/css/app.css`)
Added mobile-first breakpoints to `@theme`:
- `--breakpoint-xxs: 320px` (iPhone SE, small Android)
- `--breakpoint-xs: 375px` (iPhone 12/13/14 standard)
- Default breakpoints retained: sm, md, lg, xl, 2xl

### 2. Mobile Touch-Friendly CSS (`resources/css/prism-tokens.css`)
- `.glass-input`: `min-height: 44px`, `font-size: 16px` on mobile (prevents iOS zoom)
- `select.glass-input`: Enhanced padding
- Touch-friendly buttons: `min-height: 44px`, `min-width: 44px` on mobile
- `@media (max-width: 767px)` media queries for mobile-specific styles

### 3. Backoffice Layout (`resources/views/layouts/backoffice.blade.php`)
- **Mobile hamburger menu**: Toggle button in header (hidden on lg+)
- **Off-canvas sidebar**: Slides in from left on mobile, fixed overlay
- **Responsive padding**: `p-3 lg:p-6` on main content
- **Responsive header**: `px-4 lg:px-6`, hamburger button with aria attributes
- **Alpine.js state**: `sidebarOpen` with transitions

### 4. POS Kasir Page (`resources/views/modules/pos/livewire/pos-kasir.blade.php`)
- **Product grid**: Responsive `grid-cols-1 xxs:grid-cols-2 xl:grid-cols-3`
- **Touch-friendly toolbar**: `py-2.5`, `text-sm`, `flex-wrap`
- **Cart panel**:
  - **Desktop (≥1024px)**: Fixed side panel (original behavior)
  - **Mobile (<1024px)**: Bottom sheet with drag handle, overlay, swipe-to-close
  - **Mobile toggle button**: Sticky bottom button showing cart count
- **Cart content partial** (`resources/views/modules/pos/livewire/partials/cart-content.blade.php`):
  - Quantity controls: `w-10 h-10` (44px) touch targets
  - Action buttons: `min-h-[44px]`
  - Payment summary with tier badge
  - Transaction hold buttons (Tahan/Ditahan)

### 5. Touch Targets Throughout
- All form inputs: `min-height: 44px` via `.glass-input`
- All buttons: `min-height: 44px`, `min-width: 44px` on mobile
- Font size 16px on mobile inputs (prevents iOS zoom)

## Acceptance Criteria ✅

- [x] Text readable without browser zoom

- [x] Sidebar works as off-canvas on mobile
- [x] POS cart works as bottom sheet on mobile
